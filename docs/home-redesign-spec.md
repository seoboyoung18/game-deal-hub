# 딜모아 — 홈 리디자인 명세 (v2, GameTopia 톤)

> 목표: 라벤더/보라 그라데이션의 감성 랜딩. 기능·데이터(검색·통화·필터·가격비교)는 유지하고 **룩앤필만** 개편.
> 기준 톤: 보라 포인트 `#7c5ce0`, 부드러운 그라데이션, 둥근 카드(16px), 은은한 그림자.

## 화면 구성 (위→아래)

1. **헤더** — 로고(딜모아) · 네비(홈/게임/할인/가이드) · 검색 아이콘 · (장식) 로그인/회원가입. sticky·블러.
2. **히어로** (2단)
   - 좌: 배지("여러 스토어 할인을 한 곳에") · 헤드라인("모든 게임 할인을 **한눈에** 비교하세요", '한눈에' 보라 그라데이션) · 서브카피 · 큰 검색바 · 스토어 칩.
   - 우: **캐릭터 이미지 (회전 움짤)** — `src/assets/characters/` 의 이미지들을 자동 수집해 **6초마다 크로스페이드**로 교체. gif면 자체 애니메이션, png면 위아래로 떠다니는(float) 효과.
3. **오늘의 핫딜** — 큰 피처 카드(추천 1위 딜: 커버·게임명·할인율·최저가·"최저가 보기") + 우측 **최저가 랭킹**(상위 5) 사이드.
4. **추천 특가** — 카드 4개 그리드.
5. **전체 할인** — 기존 필터 바(스토어 칩·통화·가격·정렬) + 딜 그리드 + 페이지네이션. (실사용 목록)
6. **기능 소개** — 4칸(다양한 스토어 비교 · 실시간 갱신 · 안전한 구매 링크 · 통화 전환).
7. **푸터**.

## 캐릭터 회전 (핵심)
- 폴더: `frontend/src/assets/characters/*.{gif,png,jpg,webp}`
- `HeroCharacter.jsx` 가 `import.meta.glob` 로 **자동 수집** → 넣기만 하면 목록에 반영.
- 6초 간격 크로스페이드 순환. 이미지 0개면 플레이스홀더(✨) 표시.
- 유저가 AI로 뽑은 캐릭터들을 이 폴더에 넣으면 됨.

## 유지 원칙
- 스토어 뱃지 색·할인율 티어 색은 그대로.
- USD/KRW 토글·스팀 실가·검색·상세 가격비교 로직 변경 없음.
- 로그인/회원가입·게임/가이드 네비는 지금은 **장식**(기능 없음/추후).

## 진행 단계
- R1: 명세 + 히어로 2단 + 캐릭터 회전 ← (지금)
- R2: 오늘의 핫딜 + 최저가 랭킹 + 추천 특가 섹션
- R3: 헤더 네비 + 기능 소개 + 푸터 + S2/S3 톤 통일
