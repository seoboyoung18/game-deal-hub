# 히어로 캐릭터 이미지

여기에 캐릭터 이미지를 넣으면 홈 히어로 우측에서 **6초마다 자동으로 바뀌며** 표시됩니다.

- 지원 형식: `.gif` `.png` `.jpg` `.webp`
- **움직이는 캐릭터**를 원하면 `.gif`(움짤)로 넣으세요 — 자체 애니메이션 재생됩니다.
- `.png`/`.webp` 는 위아래로 떠다니는(float) 효과가 자동 적용됩니다.
- 파일 개수 제한 없음. 넣기만 하면 자동 수집(`import.meta.glob`)되어 순환합니다.
- 배경이 투명한 이미지(투명 PNG/WebP)가 그라데이션 배경과 가장 잘 어울려요.
- 권장 비율: 세로형(3:4 정도), 최소 폭 600px+.

예) `char1.gif`, `mage.png`, `knight.webp` ...
